Jekyll site for FLwatch

- Place this repository's contents on the `gh-pages` branch.
- GitHub Pages will serve the site at: https://poml88.github.io/flwatch-website
- The site uses language subpaths: /en/, /de/, /fr/, /es/, /ja/, /zh-Hans/
- The English landing page uses the provided DESCRIPTION content.
- Update `_data/translations.yml` for SEO/localized strings.
- The top-level index redirects to a language-aware page.
